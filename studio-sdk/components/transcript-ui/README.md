# Vue 3 + TypeScript + Vite

This template should help get you started developing with Vue 3 and TypeScript in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about the recommended Project Setup and IDE Support in the [Vue Docs TypeScript Guide](https://vuejs.org/guide/typescript/overview.html#project-setup).

## Fixtures de développement

`public/projet-libre-openstreetmap.mp3` est extrait du podcast *State of the Map 2026 à Paris*, publié par [Projets Libres !](https://www.projets-libres.org/podcast/72-state-of-the-map-2026-a-paris/) sous licence [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) ou ultérieure.

`projet-libre-openstreetmap.json` et `projet-libre-openstreetmap_whisperx.json` sont des transcriptions dérivées de cet audio ; conformément à la clause ShareAlike de la licence, elles sont mises à disposition sous la même licence CC BY-SA — distincte de la licence AGPL v3 du code de ce dépôt.

Ces fichiers ne sont utilisés que par `App.vue` (le playground de dev) et ne sont pas inclus dans le build publié (`public/` n'est pas copié dans `dist/`).
